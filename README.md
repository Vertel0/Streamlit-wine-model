# Демо-приложение для оценки качества вин (Streamlit)

Интерактивное веб-приложение для сомелье сервиса винных подписок. Приложение позволяет оценивать качество вин на основе обученной модели логистической регрессии, варьировать рабочий порог классификации, делать пакетные предсказания по CSV-файлам и анализировать важность характеристик.

---

## Требования и стек

- **Python**: `3.10` или `3.11` (проверено на Python 3.11.9)
- **Библиотеки**: `streamlit`, `scikit-learn`, `pandas`, `numpy`, `matplotlib`, `seaborn`, `joblib`

---

## Инструкция по запуску

1. Склонируйте репозиторий или перейдите в папку с приложением:
   ```bash
   cd wine_app
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение Streamlit:
   ```bash
   streamlit run app.py
   ```

После выполнения команды в консоли отобразится локальный адрес (обычно `http://localhost:8501`), который автоматически откроется в вашем браузере.

## Кэширование в Streamlit

1. Модель является тяжелым объектом, состояние которого не изменяется в процессе инференса. Декоратор `st.cache_resource` кэширует глобальные ресурсы и возвращает ссылку на один и тот же объект, избегая дорогостоящей сериализации и повторного чтения с диска.

2. `test.csv` и непрерывные оценки вероятностей (`predict_proba`) не зависят от положения слайдера порога. Декоратор `st.cache_data` вычисляет вероятности ровно один раз. При изменении порога происходит только быстрое сравнение закэшированного массива вероятностей с новым порогом, без повторного прогона матрицы признаков через модель,`st.cache_data` создает копию данных для каждой сессии.

3. Если вызвать `joblib.load` без декоратора, то модель будет загружаться и десериализоваться с жесткого диска заново при каждом клике или сдвиге слайдера.
